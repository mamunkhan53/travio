Create a new page with the URL:

`/travio-bangla`

This page will be completely separate from the existing homepage.

---

### 2. Homepage only

This page should use the **same design, layout, sections, animations, colors, and components** as the current homepage.

Only change the **content** to Bangla.

Everything else should remain identical.

Examples:

* Hero Section
* Features
* Why Choose Us
* Pricing
* FAQ
* CTA
* Footer

All text should be in Bangla.

---

Do **NOT** create Bangla versions of other pages.

Example:

* `/travio-bangla` → Bangla Homepage

* Features → `/features` (English)
* Login → `/login`
* Register → `/register`

Only the homepage content is Bangla.

**Bangla Portal**

It should link to:

`/travio-bangla`
