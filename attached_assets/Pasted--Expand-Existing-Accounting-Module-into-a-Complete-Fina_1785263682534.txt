## Expand Existing Accounting Module into a Complete Finance & Accounting System

Do **not** create a separate **Finance** menu. Instead, enhance the existing **Accounting** module into a complete Finance & Accounting system while keeping all current features intact.

**Important:**

* Do not remove or change any existing Accounting functionality.
* Keep the current UI style consistent.
* Integrate all new features with the existing Sales, Invoice, Customer, Staff, and Expense modules.
* Do **not** add Multi-Currency support. The ERP already supports a base currency selected during Agency registration, and all accounting should use that currency.

### Updated Accounting Menu Structure

```text
Accounting
│
├── Dashboard
├── Chart of Accounts
├── General Ledger
├── Cash Book
├── Bank Book
├── Income
├── Expenses
├── Accounts Receivable
├── Accounts Payable
├── Journal Entries
├── Payment Vouchers
├── Receipt Vouchers
├── Profit & Loss
├── Balance Sheet
├── VAT / Tax Reports
├── Financial Reports
└── Settings
```

## Integration Requirements

* Keep all existing Accounting features working.
* Integrate with the current Invoice module.
* Integrate with Customer profiles.
* Integrate with Staff permissions.
* Integrate with Sales and Expense modules.
* Integrate with Dashboard statistics.
* Maintain complete transaction history.
* Every financial record should store:

  * Created By
  * Created Date
  * Last Updated
  * Reference Number
* Follow the existing ERP design and coding standards.
* Ensure all new features work without affecting existing modules or data.
